# スマホレイアウトの基本

スマホでは以下の構造にする。

```
HERO
↓
ABOUT
↓
EVENT
↓
VENUE
↓
STAY / FOOD
↓
ACCESS
↓
PRICE
↓
JOIN
↓
FAQ
↓
FOOTER
```

重要ルール

* テキストは横幅いっぱいにしない
* CTAは大きめ
* セクション余白を広くする
